# Payment Method Logos

Place payment method logos in this directory with the following filenames:

- `momo-logo.png` - MoMo e-wallet logo
- `zalopay-logo.png` - ZaloPay e-wallet logo  
- `stripe-logo.png` - Stripe payment gateway logo
- `paypal-logo.png` - PayPal logo

## Recommended specifications:
- Format: PNG with transparent background
- Size: 200x200px minimum
- High resolution for retina displays

## Fallback behavior:
If logo images are not found, the checkout page will display FontAwesome icons as fallbacks:
- COD: `fa-money-bill-wave`
- Bank Transfer: `fa-university`
- MoMo/ZaloPay: `fa-wallet`
- Stripe: `fa-credit-card`
- PayPal: `fab fa-paypal`
